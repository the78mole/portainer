📋 How to Verify PGP Secrets

To check if your PGP secrets are working correctly:

  1. Check Container Logs: 
    docker-compose logs web
  2. Inspect Environment Variables: 
    docker-compose exec web env | grep -E "(PUBLIC_VAR|DATABASE_PASSWORD|API_TOKEN|WEBHOOK_SECRET)"
  3. Access the PHP Version:

    Visit index.php for dynamic environment variable display

  4. Check Portainer Logs:

    Look for messages like "Successfully decrypted and loaded PGP secrets" in Portainer logs

✅ Expected Environment Variables

If PGP decryption is working correctly, these variables should be available to the container:

Public Variables (from stack.env):

PUBLIC_VAR: hello_world
APP_NAME: PGP Demo Stack
DEBUG: false

Secret Variables (from stack.secrets.env.pgp):

DATABASE_PASSWORD: super_secret_db_password_123
API_TOKEN: sk_live_abc123xyz789_secret_token
WEBHOOK_SECRET: whsec_example_webhook_secret_456

🔧 Troubleshooting

  • Secrets not loaded: Check if PGP private key is configured in Portainer Settings
  • Wrong passphrase: Ensure passphrase "demo123" is entered correctly
  • File not found: Verify stack.secrets.env.pgp exists in the stack directory
  • Decryption fails: Check Portainer logs for PGP-related error messages
